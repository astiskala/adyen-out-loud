# Changelog

All notable changes to this project are documented here. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versioning follows
[Semantic Versioning](https://semver.org/) once the first release is tagged (see
[`docs/releasing.md`](docs/releasing.md)).

## [Unreleased]

### Added
- Full engineering-quality tooling: C# nullable/analyzer strictness, `dotnet format` enforcement,
  strict MAUI XAML compilation, TypeScript strict mode plus stricter compiler options, ESLint +
  Prettier for the Worker, `wrangler types` generation and CI drift check, architecture tests for
  both the .NET solution and the Worker (`dependency-cruiser`), `knip` dead-code detection,
  coverage thresholds and reporting for both sides, CodeQL, Dependabot, GitHub Actions CI
  (`quality`, `platform-builds`, `codeql`, `dependency-review`, `scheduled-deep-quality`), and the
  open-source governance/documentation set (README, `AGENTS.md`, `CONTRIBUTING.md`, `SECURITY.md`,
  `CODE_OF_CONDUCT.md`, `SUPPORT.md`, `docs/architecture.md`, `docs/threat-model.md`,
  `docs/privacy.md`, and Architecture Decision Records under `docs/adr/`).
- `AdyenOutLoud.Core.Services.SpeechLocaleSelector` — the TTS voice-selection algorithm, extracted
  from `MauiSpeechService` into an independently unit-testable pure function.
- Adversarial/negative test coverage for both webhook parsers and the relay protocol parser.
- A regression test asserting the instance token never appears in any log output, including on the
  Worker's error-logging path.

### Changed
- The app's supported languages corrected from an unrelated `en/nl/de/fr` set to the
  project's actual target set: English, Chinese, Malay, and Tamil (`en-SG`/`zh-SG`/`ms-SG`/`ta-SG`)
  — this was a genuine functional gap, not a cosmetic rename. See
  [ADR 0006](docs/adr/0006-on-device-text-to-speech.md).
- The Worker's `Env` type is now generated by `wrangler types` from `wrangler.jsonc` instead of
  hand-maintained, removing a source of drift between bindings and their types.
- Central Package Management adopted for the .NET solution (`Directory.Packages.props`).

### Fixed
- Several real analyzer findings surfaced by the new strictness settings (disposable fields not
  implementing `IDisposable`, a culture-sensitive `DateTimeOffset.Parse` in a test, an
  AOT/trim-unfriendly reflection-based JSON call replaced with a source-generated
  `JsonSerializerContext`) — see the hardening pass's final report for the full list.

## [0.1.0] — unreleased baseline

The state of the repository before this hardening pass: a working .NET MAUI client and Cloudflare
Worker with an already-clean architecture (Core/MAUI separation, TypeScript strict mode, a
substantial Worker integration test suite covering correlation, deduplication, and WebSocket
replay) but without the surrounding quality gates, CI, or documentation this hardening pass added.
No tag exists for this state; it's recorded here only as the changelog's starting point.
