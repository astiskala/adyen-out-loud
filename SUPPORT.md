# Support

## GitHub Issues

Use [GitHub Issues](../../issues) for:

- Reproducible bugs in the app or the Worker (use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.yml))
- Feature requests (use the [feature request template](.github/ISSUE_TEMPLATE/feature_request.yml))

Please don't paste any real payment data into an issue — see
the warnings in the bug report template and [`docs/threat-model.md`](docs/threat-model.md).

## Security vulnerabilities

**Do not** file a public issue for a security vulnerability. See [`SECURITY.md`](SECURITY.md) for
how to report one privately.

## This project is not Adyen Support

This repository is an independent, unofficial project — see the
[trademark and non-affiliation note](README.md#trademark-and-non-affiliation). It is **not** a
channel for:

- Adyen merchant account issues
- Payment disputes, chargebacks, or transaction investigations
- Terminal hardware problems
- Anything specific to your Adyen Customer Area configuration

For any of the above, contact [Adyen Support](https://www.adyen.com/contact) directly.

## Questions about how something works

Check [`docs/`](docs/) first — [`docs/architecture.md`](docs/architecture.md),
[`docs/protocol.md`](docs/protocol.md), and [`docs/index.md`](docs/index.md) cover most
"how does X work" questions. If the docs don't answer it, a GitHub issue (not a feature request —
just ask) is fine.
